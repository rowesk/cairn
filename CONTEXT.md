# Cairn

Cairn keeps pages made from chat requests in the owner's private, searchable library.

## Language

### Page

A saved answer intended to be read outside chat, with a title, its creating agent, creation date, and the request that prompted it.

### Library

the owner's private collection of saved pages. Sharing a page does not grant access to the library.

### Private page

A page accessible only from the owner's authorised devices. New pages start private.

### Shared page

A page The owner has explicitly made accessible through a public link, optionally protected by a password. The owner can turn this access off.

### Public link

An address for one shared page on the owner's domain, with a readable or random path. It grants no access to the library or other private pages.

### Template

A reusable layout and styling for a type of Cairn page. Agents use a suitable template by default and can depart from it when the content benefits.

### Original request

the owner's words that prompted a page, retained as private context. Sharing a page never shares this request or the surrounding chat.

### Agent byline

The name of the agent that prepared a page, shown on both private and public views.

### Archived page

A page hidden from the main library list but available through the Archived filter and its existing links.
