Key for

can publish private pages under its name, and list, read, replace and archive those pages through the API. The key is a byline, not a lock: software that can reach your library can do anything you can, so connect only agents you trust.

  1. Create a key

    Cairn shows the key once, here, for you to copy into the agent’s secret store.

  2. Copy the key

    Save it in the agent’s secret store as CAIRN_API_KEY. You won’t see this key again: Cairn keeps only a fingerprint of it.

  3. Give the agent its instructions

    The setup text says when and how to publish. It reads the key from CAIRN_API_KEY and holds no secret, so it’s safe to paste into a chat or a project file.

  4. Test it

    Run this where the agent runs, with CAIRN_API_KEY set:

    Success is a reply that starts {"pages": and lists the pages has written. invalid_credential means the key didn’t reach the command.

Cairn can’t show this key again. If the agent lost it, or someone else may have it, rotate it for a new one or revoke it.
